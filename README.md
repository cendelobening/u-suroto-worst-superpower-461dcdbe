A one-line entry for the [Worst Superpower bounty](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe): invent the most useless superpower imaginable.

## Entry

> I can read minds, but only my own, and only thoughts I have already had.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) with world-readable `0644` permissions.

Run it:

```sh
python3 main.py
```
